# Build targets
Root CMake project builds faithful and optional enhanced C++ targets. With PRESSKIT_BUILD_PLAYER=ON, faithful/presskit_player and enhanced/presskit_player_enhanced are separate executables, both use the C++ reference Qt host; enhanced chooses opt-in gallery fixes. Rust workspace is independent, primary, and uses wgpu/winit with Slang 2026.22.1 generated WGSL, verified with Rust 1.100.0 installed from R2. Do not route private application compilation through public handoff workflows. Public toolchain/dependencies only. Rust is currently a development host with baked original frames and missing media integration; vector artwork and platform hosts are future work.
