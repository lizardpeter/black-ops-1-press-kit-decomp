# Enhanced Rust (primary target)

Rust 2024, pinned R2 toolchain 1.100.0. Independent of C++, Qt and Flash. Workspace: core (pure app state and original-derived hit regions), renderer (wgpu texture compositor), app (winit native development host). `cargo test -p presskit-core` and `cargo run -p presskit-app -- /path/to/prepared-assets`. Initial native development host uses explicitly labeled hand-authored WGSL fallback; compile canonical Slang source with `python3 tools/compile_shaders.py --out /tmp/presskit-shaders`. Generated shader integration/validation pending. Video/audio, original controls, mobile and browser host are not implemented in this commit. Enter skips unavailable media in dev host. No platform claimed verified without test. Source assets remain external; see root tools/prepare_player_assets.py. No private source sent to public runners.
