## Self-contained WebAssembly/WebGPU site build

The public R2 prefix is a **build-time source only**. The GitHub Actions workflow downloads all 44 objects (409,146,676 bytes) from `https://r2.houseofkublai.com/bo1-press-kit/payload/`, verifies each object's exact size and MD5/ETag, and places them under `web/assets/payload/` before packaging. The original payload is never committed to Git history. The browser resolver maps every `payload/**` path to the same-origin `assets/payload/**` directory; the running site makes no R2 requests and needs no R2 CORS configuration.

The website contains the full original media collection, but it is **not downloaded all at startup**. The intro/trailer video source is attached only when playback begins, gallery XML is fetched when entering the gallery, screenshots are fetched through the bounded demand-first asset queue, and wallpapers are fetched only when opened. The browser initially loads the WASM runtime and compact reconstructed art only.

The workflow publishes a downloadable `webgpu-self-contained-site` Actions artifact (30-day retention) and attempts GitHub Pages deployment. The full site is about 414 MB, under GitHub Pages' 1 GB published-site limit. If Pages is not enabled yet, the build artifact still succeeds; enable repository Settings → Pages → Build and deployment → Source = GitHub Actions, then rerun the workflow. Local testing uses the same extracted site folder served from `http://localhost:8000`. A visible educational/non-affiliation disclaimer is included in the browser UI.

### Publishing after enabling GitHub Pages
After selecting **Settings → Pages → Build and deployment → GitHub Actions**, push this README or any other change under `enhanced-rust/` to `main`, or use Actions → `webgpu-test-build` → Run workflow. The workflow rebuilds and verifies the complete static package, then deploys that exact artifact. A green build alone does not mean browser GPU playback has been tested; use `web/browser-smoke.mjs` on a WebGPU-capable browser/machine for that separate end-to-end check.
